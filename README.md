Using drone multispectral imagery to detect and correlate plant diseases

This project focuses on analyzing drone-acquired multispectral imagery to establish correlations between spectral signatures and the presence of plant diseases. 
By integrating remote sensing technology with data analytics, the study aims to develop a non-invasive method for monitoring crop health.

High-resolution multispectral images captured by drones will be processed to extract vegetation indices such as the Normalized Difference Vegetation Index (NDVI).
These indices will then be statistically compared with ground-truth data obtained from field disease assessments. Correlation plots and regression analyses 
are expected as the final output from the data flow diagram. 

By implementing the data flow, I aim to establish a structured and repeatable framework for linking drone-based multispectral data with plant health metrics, 
ensuring that every dataset passes through a standardized process (calibration, validation, and feature extraction) to guarantee consistency and reproducibility.
